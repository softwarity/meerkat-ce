Access tokens

Console tokens open this console's API without a browser - a script, a pipeline, a backend managing its scheduled calls - with your own powers, narrowed by a perimeter; they are created here. Application tokens call the applications' APIs: each person creates their own, on their profile on the applications, and those who administer the applications see and revoke them here. To connect an assistant, use the MCP section: it needs no token.
