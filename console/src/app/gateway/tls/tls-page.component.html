Automatic certificates (ACME)

A certificate has to be signed by someone browsers trust, and it expires - ninety days with Let's Encrypt. ACME is the gateway asking an authority for one directly: it proves it controls the name, receives the certificate, and renews weeks before the expiry. Nobody touches a file, and nobody has to remember.

The proof is what sets the condition: the authority connects to the name itself, so a public one only works for a name that resolves on the internet and reaches this gateway. The exchange runs on the HTTPS port already held here - port 80 stays closed.
