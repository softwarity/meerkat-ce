Deploy a collector

Two tiers of Collector, then set the agent's address here. Put their UIs behind a route on this gateway.

  1. An agent on every node (DaemonSet, Swarm global): the one address every service sends to, and the reader of the containers' stdout (OpenTelemetry JSON). It writes the metrics to Prometheus and the logs and audit to Loki.
  2. A gateway: the agents send it the traces only, every span of a trace to the same replica. Once a trace is complete it keeps it or not (tail sampling: every error, every slow one, a share of the rest) and writes it into Tempo.

Why two: a trace's spans are made on several nodes, and an agent sees only its own, so it cannot decide which traces to keep. With the gateway deciding, record 100% here.

Set your Tempo, Prometheus and Loki addresses in the files. Includes Grafana sources and a dashboard.
