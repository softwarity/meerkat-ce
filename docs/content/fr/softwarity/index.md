# Softwarity

Softwarity écrit des logiciels pour ceux qui écrivent des logiciels en
entreprise. Notre terrain, ce sont les **applications internes** que porte une
direction informatique : celles qui ont de vrais utilisateurs, de vraies
données, de vraies règles d'accès, et une petite équipe derrière elles.

Ces équipes finissent toutes par écrire les mêmes choses. Une page de
connexion. Un modèle de rôles. Une table d'utilisateurs. Un journal d'audit
réclamé après un incident. Une configuration de gateway à laquelle personne
n'ose toucher un vendredi. Ce travail est nécessaire, il n'est jamais
l'essentiel, et c'est là que passent les semaines.

::: lead
Notre réponse consiste à sortir cette moitié de l'application pour la mettre à
sa place : devant elle. C'est ce qu'est [Meerkat](/index), et c'est le principe
de tout ce que nous faisons - la part répétitive devient un produit, pour que
la part qui vous appartient reste la vôtre.
:::

## Ce que nous faisons

::: cards
### Des produits

[Meerkat](/index), l'app-gateway : une porte unique devant une application
interne, qui se charge de l'authentification, des règles d'accès, des
organisations, du routage, des quotas et de l'audit. Son ancêtre, **Archway**,
faisait le même travail sur une base Spring Cloud Gateway. Il nous a appris ce
qu'il fallait faire autrement - et jusqu'où l'idée pouvait être poussée.

### Des outils

[plug](https://github.com/softwarity/plug) fait entrer le poste d'un
développeur dans un cluster : un service qui tourne sur un ordinateur portable
répond sous son nom de cluster, et tout le reste continue comme avant.

### De l'open source

Une étagère de composants Angular dont nous avions besoin, publiés au lieu
d'être recopiés d'un projet à l'autre : rails de navigation, actions de ligne,
indicateurs de chargement, sélecteurs de fuseau horaire. Voir
[Open source](/softwarity/open-source).
:::

## Ce sur quoi vous pouvez compter

Placer une gateway devant vos applications vous engage pour longtemps.
Voici donc ce que vous obtenez de notre côté.

**Vous pouvez vérifier le produit avant de lui faire confiance.** Ce qui est
construit et ce qui ne l'est pas tient dans un seul tableau du dépôt, lu dans
le code et non dans un plan. Rien sur ce site n'annonce "bientôt disponible"
pour quelque chose qui n'existe pas.

**Vous n'êtes pas captifs.** Le code source du cœur est accessible, et il
passe sous licence Apache 2.0 deux ans après la publication de chaque
version : ce que vous déployez aujourd'hui ne pourra pas vous être retiré.
Toute votre configuration s'exporte dans un seul fichier, que vous pouvez lire
et rejouer ailleurs. Et la gateway ne nous envoie rien, jamais : elle ne
contient aucune télémétrie.

**Quand quelque chose ne va pas, vous joignez ceux qui l'ont écrit.** Il n'y a
pas de niveau de support intermédiaire entre vous et le code.
