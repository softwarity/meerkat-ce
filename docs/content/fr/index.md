# Documentation

Meerkat est une app-gateway : une porte unique devant vos applications
internes, qui prend en charge l'authentification, les regles d'acces, le
routage et l'observation, pour que vos services n'aient pas a le faire.

## Par ou commencer

- **[Ce qu'est Meerkat](/#/docs/start/what-is-meerkat)** - ce que fait le produit, en deux minutes.
- **[Demarrage rapide](/#/docs/start/quick-start)** - une gateway qui tourne et une premiere application derriere.
- **[Concepts](/#/docs/concepts/architecture)** - les deux plans, les routes, l'identite, les acces.

## Reference

- **[Predicats](/#/docs/predicates/overview)** - les onze facons pour une route de decider qu'une requete est pour elle.
- **[Filtres](/#/docs/filters/overview)** - les trente-trois facons de la transformer.
