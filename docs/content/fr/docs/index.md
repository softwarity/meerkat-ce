# Documentation

Meerkat est une app-gateway : une porte unique devant vos applications
internes, qui prend en charge l'authentification, les règles d'accès, le
routage et l'observation, pour que vos services n'aient pas à le faire.

## Par où commencer

- **[Ce qu'est Meerkat](/product/what-is-meerkat)** - ce que fait le produit, en deux minutes.
- **[Démarrage rapide](/docs/start/quick-start)** - une gateway qui tourne et une première application derrière.
- **[Concepts](/docs/concepts/architecture)** - les deux plans, les routes, l'identité, les accès.

## Référence

- **[Prédicats](/docs/predicates/overview)** - les onze façons pour une route de décider qu'une requête est pour elle.
- **[Filtres](/docs/filters/overview)** - les trente-trois façons de la transformer.
- **[La console](/docs/console/overview)** - chaque écran, et à quoi il sert.

- **[Déployer](/docs/deploy/one-gateway)** - Docker, Helm, et ce que décide chaque variable.
- **[Cluster Kubernetes](/docs/deploy/kubernetes)** - plusieurs gateways derrière une seule entrée.
